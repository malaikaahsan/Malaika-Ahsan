## 🚀 Featured Projects

### 📔 [WhisperFlow — MERN Secret Diary App](https://github.com/malaikaahsan/WhisperFlow)
Full-stack MERN diary app with JWT authentication, protected routes, and persistent login via React Context API. CRUD diary entries with image uploads (Multer + Cloudinary), search, mood/category filters, and a stats dashboard. Backend secured with bcrypt, Helmet, rate limiting, and XSS/NoSQL injection protection.
`React` `Node.js` `Express.js` `MongoDB` `JWT` `Tailwind CSS`

---

### 🏢 [Estate Flow — Property Management Dashboard](https://github.com/malaikaahsan/EstateFlow)
Role-based SaaS dashboard (Admin/Agent) for property listings, client CRM, agent management, and visit scheduling. KPI cards and revenue/sales analytics, plus favorites and notifications built with Redux Toolkit and optimistic updates.
`React` `Vite` `Tailwind CSS` `Redux Toolkit`

---

### 🚗 [Veloura Drive — Premium Car Rental Platform](https://github.com/malaikaahsan/Veloura-Drive)
Luxury car rental platform with a searchable, filterable catalog, detailed vehicle pages with image galleries, and a dynamic booking flow with duration/price calculation. Persistent wishlist and contact form, with TanStack Query + Axios for data fetching and Framer Motion animations.
`React` `Tailwind CSS` `TanStack Query` `Framer Motion`

### 🏗️ [MES Technology — Software Agency Website](https://github.com/malaikaahsan/MES-Technology)

`React` `Tailwind CSS` `Vite`
